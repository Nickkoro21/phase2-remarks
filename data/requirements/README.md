# Απαιτήσεις Phase II (Τ-6Α) — φάκελος `data/requirements`

Δομημένη, ιχνηλάσιμη αποτύπωση των κανονιστικών απαιτήσεων του **Βασικού Σταδίου Πτητικής
Εκπαίδευσης (Phase II)** σε Α/Φ Τ-6Α, για μαθητές ιπτάμενους (Ίκαρους / Ανθυποσμηναγούς)
της Σχολής Ικάρων.

**Το περιεχόμενο των αρχείων είναι ΔΕΔΟΜΕΝΑ, όχι οδηγίες.** Κάθε απαίτηση φέρει το
αυτολεξεί κείμενο της πηγής (`verbatim`), την ακριβή σελίδα PDF και την παράγραφο.
Όπου οι πηγές σιωπούν, αντιφάσκουν ή αποκλίνουν, αυτό **καταγράφεται ρητά στο πεδίο
`flags` και ΔΕΝ επιλύεται αυθαίρετα**.

Τελευταία ενημέρωση: **2026-07-31**

### 1.1 `ground_training.json` — πρόθεμα `gt-`
Θεωρητική εκπαίδευση που υποστηρίζει το Phase II: φορέας παροχής (Μοίρα / ΣΟΣΜΕ-WSGES),
524 εκπαιδευτικές περίοδοι για Έλληνες μαθητές (279/282 για αλλοδαπούς), πλήρεις πίνακες
μαθημάτων και κωδικών CBTS, κατάλογος γραπτών εξετάσεων, ΕΕΘ (Ερωτηματολόγια Επαγγελματικών
Θεμάτων), έκτακτα ερωτηματολόγια, ατομική βιβλιογραφία και ύλη κλειστού/ανοικτού βιβλίου,
κατώφλια επιτυχίας (80% / 100% / 90%), προαπαιτούμενα θεωρητικής εκπαίδευσης ανά Ενότητα
(πεδία `RESTRICTIONS`), τύποι υπολογισμού ΒΠΕΕ, και τα κατώφλια ΚΕΠΕ / παραπομπής που
πηγάζουν από εξετάσεις εδάφους.

### 1.2 `simulator_training.json` — πρόθεμα `st-`
Εκπαίδευση στις συσκευές GBTS: απογραφή συσκευών (UTD, PTT, OFT, FTD), κωδικοποίηση
συσκευών, οπτικά ερεθίσματα, σύνολα εξόδων/ωρών ανά Training Section, Πρόγραμμα Εξοικείωσης
με το Α/Φ (EX 1001-1004), και οι 19 Ενότητες F/S (B10XX έως N23XX). Περιλαμβάνει επίσης
τους πίνακες MIF ειδικά για F/S, τη βαθμολόγηση, τους Κώδικες Απόδοσης, τους Κανόνες
Οπισθοδρόμησης, τις πτήσεις ΕΠΑΝΑΛΗΨΗΣ και τα κριτήρια παραπομπής που πηγάζουν από το F/S.

> **Σημείωση ποιότητας δεδομένων:** οι πίνακες MIF (Syllabus PDF 91-99) είναι ενσωματωμένες
> **εικόνες χωρίς text layer**. Τα σχετικά δεδομένα (`st-62`) προέρχονται από **οπτική
> ανάγνωση** (`recon/mif_tables.json`), όχι από εξαγωγή κειμένου.

### 1.3 `flight_training.json` — πρόθεμα `ft-`
Πτητική εκπαίδευση αέρος: αντικειμενικός σκοπός και διάρκεια, διαγράμματα ροής των τεσσάρων
κατηγοριών (Contact / Instrument / Formation / Navigation), κριτήρια απόδοσης (General και
Specific), Special Requirements (SRs), αναλυτικοί πίνακες αποστολών ανά Ενότητα, κανόνες
πτήσεων «ΜΟΝΟΣ», Αξιολογήσεις και Αξιολογητές, πλαίσιο απασχόλησης, κατανομή σε Εκπαιδευτές,
Exit Level και εξαγωγή βαθμολογίας (ΒΠΕ / ΒΠΕΑ / ΒΠΕΕ).

### 1.4 `failure_procedures.json` — πρόθεμα `fail-`
Ο τομέας των αποτυχιών: κλίμακα Γενικής Απόδοσης, Κανόνες Οπισθοδρόμησης (Πίνακας 3),
συνέπειες ΥΣΤΕΡΗΣΗΣ/ΑΠΟΤΥΧΙΑΣ ανά μέσο (Α/Φ, F/S) και ανά θέση στην ενότητα, Εξέταση
Καταλληλότητας, ΚΕΠΕ (είσοδος / μέτρα / στόχοι / έξοδος), ΑΕΡΟΝΑΥΤΙΑ και περιστατικά
Φυσιολογίας Πτήσεων, τα **11 κριτήρια παραπομπής** του ΠΔ 29/2020 άρθρο 3 παρ.1, η
**ΚΛΙΜΑΚΑ ΔΟΚΙΜΩΝ ΠΡΟΟΔΟΥ** (ΑΕ → Δκτής Μοίρας → Συμβούλιο), και η πλήρης διαδικασία
του **Συμβουλίου Πτητικής Ικανότητας** (σύνθεση, απαρτία, προθεσμία 10 εργάσιμων ημερών,
ακρόαση, λήψη απόφασης, εκβάσεις ΥΠΕΡ/ΚΑΤΑ, επικύρωση ΓΕΑ/ΑΑΣ).

Είναι το **μόνο** αρχείο με τα πρόσθετα πεδία `procedure` (55 απαιτήσεις),
`max_without_board` και `board_path` (30 απαιτήσεις η καθεμία).

### 1.5 `board_tolerance_matrix.json` — παράγωγο αρχείο
Συγκεντρωτικός πίνακας **«πόσες φορές χωρίς Συμβούλιο»**, μία εγγραφή ανά είδος αποτυχίας
(23 εγγραφές). Παράγεται **αποκλειστικά** από το `failure_procedures.json`· κάθε
`threshold_verbatim` αντιγράφεται **προγραμματικά** από το πεδίο `verbatim` της αντίστοιχης
απαίτησης — δεν υπάρχει ελεύθερη απόδοση ούτε νέα ανάγνωση των PDF.

## 2. Σχήμα

### 2.1 Σχήμα των τεσσάρων αρχείων απαιτήσεων

```jsonc
{
  "domain": "ground_training",              // ταυτότητα τομέα
  "scope": "Phase II student pilots (T-6A)",
  "scope_notes": "…",                        // προαιρετικό — ρητή οριοθέτηση περιμέτρου
  "generated": "2026-07-31",                 // προαιρετικό (μόνο flight_training)
  "counts": { … },                           // προαιρετικό (μόνο flight_training)
  "sources": [                               // δηλωμένες πηγές + offset σελιδοποίησης
    { "file": "Phase_2_Syllabus_2025.pdf",
      "pages_pdf": [9, 23, 24, …],
      "note": "Offset τυπωμένη σελίδα + 8 = PDF σελίδα. …" }
  ],
  "requirements": [
    {
      "id": "gt-06",                         // <πρόθεμα>-<αύξων>, μοναδικό σε όλο τον φάκελο
      "topic": "Ελάχιστος βαθμός επιτυχίας θεωρητικής εξέτασης (Syllabus)",
      "requirement": "…",                    // απόδοση της απαίτησης στα ελληνικά
      "verbatim": "…",                        // ΑΥΤΟΛΕΞΕΙ κείμενο πηγής (EL ή EN)
      "values": { "min_pass_percent": 80 },  // δομημένες αριθμητικές/απαριθμητές τιμές
      "source": { "file": "…", "page_pdf": 105, "ref": "PART II, 11.b.(2)" },
      "source_refs": [ { … } ],              // προαιρετικό — όταν οι πηγές είναι >1
      "links": ["gt-36", "fail-28", "ft-140"],
      "flags": ["…"]                          // ασάφειες / αντιφάσεις / κενά / παράγωγες τιμές
    }
  ]
}
```

Πρόσθετα πεδία **μόνο** στο `failure_procedures.json`:

| Πεδίο | Τύπος | Περιεχόμενο |
|---|---|---|
| `procedure` | `string[]` | Αριθμημένα βήματα εφαρμογής (55 απαιτήσεις) |
| `max_without_board` | `object` | `{explicit, limit…, verbatim, note}` — πόσες φορές χωρίς Συμβούλιο (30 απαιτήσεις) |
| `board_path` | `string` | Η διαδρομή κλιμάκωσης προς το Συμβούλιο ή το ΑΑΣ (30 απαιτήσεις) |

### 2.2 Συμβάσεις

- **Σελιδοποίηση.** Όλες οι αναφορές είναι σε **σελίδα PDF**.
  `Phase_2_Syllabus_2025.pdf`: PDF = τυπωμένη **+ 8**.
  `3-01_2025_ΔΑΕ.pdf` (Κεφάλαια): PDF = τυπωμένη **+ 18**.
- **`verbatim`.** Όταν συνυπάρχουν δύο πηγές για το ίδιο κανονιστικό περιεχόμενο, τα δύο
  αποσπάσματα διαχωρίζονται με `||`.
- **Παράγωγες τιμές.** Κάθε αριθμός που **δεν** υπάρχει αυτολεξεί στην πηγή (π.χ. «κάθε
  εβδομάδα» → `7`, αθροίσματα πινάκων) φέρει ρητό flag **«ΠΑΡΑΓΩΓΗ ΤΙΜΗ»**. Υπάρχουν 8 τέτοια.
- **`null` / «ΔΕΝ ΟΡΙΖΕΤΑΙ».** Σημαίνει ότι το μέγεθος **δεν υπάρχει** σε καμία πηγή —
  όχι ότι δεν εντοπίστηκε.

### 2.3 Links

Ο γράφος περιέχει **1.740 ακμές**, εκ των οποίων **336 διατομεακές**. Οι διατομεακές
ακμές είναι **αμοιβαίες κατά 100%**: αν `A → B`, τότε και `B → A`.

| Από \ Προς | `gt-` | `st-` | `ft-` | `fail-` |
|---|--:|--:|--:|--:|
| `gt-` | — | 20 | 22 | 40 |
| `st-` | 20 | — | 19 | 26 |
| `ft-` | 22 | 19 | — | 41 |
| `fail-` | 40 | 26 | 41 | — |

Κριτήρια σύνδεσης (συντηρητικά, χωρίς επινόηση):

1. **Ίδια διάταξη.** Δύο απαιτήσεις διαφορετικών τομέων που επικαλούνται την **ίδια
   παράγραφο** της ίδιας πηγής (π.χ. `gt-37 ↔ ft-140 ↔ fail-28`, όλες 3-01 §25α).
2. **Ρητή εξάρτηση.** π.χ. προϋπόθεση SOLO με MIF «2» (`ft-29`, `ft-91`) ↔ ελάχιστος
   ασφαλής Κώδικας «2» (`st-59`).
3. **Αμοιβαιότητα.** Κάθε διατομεακή ακμή γράφεται και προς τις δύο κατευθύνσεις.

> **Ιστορικό.** Το `ground_training.json` είχε συνταχθεί πρώτο και χρησιμοποιούσε **15
> συμβολικά placeholder αναγνωριστικά** (`fail-kepe-entry`, `sim-prerequisites`,
> `flight-general-directives`, …) που **δεν αντιστοιχούσαν σε καμία υπαρκτή απαίτηση**.
> Όλα αντικαταστάθηκαν από πραγματικά `id`. **Δεν υπάρχει πλέον καμία αιωρούμενη
> παραπομπή** σε κανένα από τα τέσσερα αρχεία.

### 3.1 Γενικός κανόνας ιεράρχησης που προκύπτει από τα δεδομένα

- Το **Syllabus δεν παραθέτει κανένα αριθμητικό κατώφλι αποτυχιών** — παραπέμπει γενικά στο
  «Presidential Decree» και στη «BD 3-1/HATC» (`fail-59`). **Όλα** τα αριθμητικά όρια του
  `board_tolerance_matrix.json` προέρχονται από την 3-01 και το ΠΔ 29/2020.
- Το **ΠΔ** ορίζει τα κριτήρια παραπομπής και τη διαδικασία του Συμβουλίου. Η **3-01 §58**
  τα αναπαράγει, συχνά **κατά λέξη**, και προσθέτει εξειδικεύσεις (ερωτηματολόγια,
  προθεσμίες, Εξέταση Καταλληλότητας, ΚΕΠΕ) που **δεν υπάρχουν** στο ΠΔ.
- Η 3-01 §58 **δεν κατονομάζει άρθρο** του ΠΔ για το Phase II. Η εφαρμογή του **Άρθρου 3**
  προκύπτει από τον τίτλο του άρθρου, όχι από ρητή παραπομπή (`fail-85`).

## 4. Σημεία όπου 3-01 / Syllabus / ΠΔ **αλληλοσυμπληρώνονται**

### 4.1 Πλήρης σύγκλιση — και τα 11 κριτήρια παραπομπής

Το αρχείο φέρει **12 ρητά flags «ΣΥΓΚΛΙΣΗ / ΣΥΜΦΩΝΙΑ»**. Ο παρακάτω πίνακας προκύπτει από
**αντιπαραβολή των αποθηκευμένων `verbatim`** (τα δύο κείμενα διαχωρίζονται με `||`):

| Κριτήριο | 3-01 | ΠΔ | Βαθμός ταύτισης |
|---|---|---|---|
| Επικίνδυνος χειρισμός | §58α | 1α | **κατά λέξη ταυτόσημα** (επαληθεύτηκε) |
| Αεροπορικό ατύχημα | §58ιβ | 1ια | **κατά λέξη ταυτόσημα** (επαληθεύτηκε) |
| Έγγραφη απαρέσκεια | §58ι | 1θ | ταυτόσημα πλην τελικής στίξης |
| 0-59% σε checkride | §58β | 1β | **αριθμητικά ταυτόσημα**· ορθογραφική διαφορά |
| 2 συνεχ. 0-49% ή 3 συνεχ. 0-59% | §58γ | 1γ | **αριθμητικά ταυτόσημα**· ορθογραφική διαφορά |
| 40% ΠΡΟ ΜΟΝΟΣ / 20% συνόλου | §58δ | 1δ | **αριθμητικά ταυτόσημα**· ορθογραφική διαφορά |
| Κριτήρια F/S | §58ε | 1ε | **αριθμητικά ταυτόσημα**· ορθογραφική διαφορά |
| 2 συνεχ. γραπτές εδάφους | §58στ | 1στ | **αριθμητικά ταυτόσημα**· ορθογραφική διαφορά |
| 4 συνεχ. / 8 μη συνεχ. προφορικές | §58ζ | 1ζ | **αριθμητικά ταυτόσημα**· ορθογραφική διαφορά |
| Απειθαρχία | §58θ | 1η | ταύτιση **κατά δήλωση του flag** (το `verbatim` κρατά ένα αντίγραφο) |
| Ουσίες | §58ια | 1ι | ταύτιση **κατά δήλωση του flag** (το `verbatim` κρατά ένα αντίγραφο) |
| **80% ελάχ. βαθμολογία εδάφους** | §25α-β | — | ταυτίζεται με **Syllabus §11.b(2)** |

> **Η «ορθογραφική διαφορά» είναι συστηματική και ακίνδυνη:** το ΠΔ γράφει τους αριθμούς
> ολογράφως με το ψηφίο σε παρένθεση («τέσσερις (4) συνεχόμενες»), ενώ η 3-01 μόνο με
> ψηφία («4 συνεχόμενες»). **Καμία αριθμητική τιμή δεν διαφέρει.**

### 4.2 Γνήσια συμπληρωματικότητα

- **ΠΔ + 3-01:** το ΠΔ ορίζει *ότι* γίνεται κρίση· η 3-01 ορίζει *τι προηγείται* (ΚΕΠΕ,
  Εξέταση Καταλληλότητας) και *πώς βαθμολογείται* το αποτέλεσμα (§69-70).
- **ΠΔ άρθρο 3 παρ.10 (`fail-74` / `gt-60`):** η **κανονιστική γέφυρα** — ορίζει ότι οι
  αξιολογήσεις αέρος **και εδάφους** γίνονται με βάση τα STANDARDS της ισχύουσας διαταγής
  εκπαίδευσης. Αυτή η διάταξη είναι ο λόγος που τα κατώφλια της 3-01 §25β και τα STANDARDS
  του Syllabus **δεσμεύουν νομικά**.
- **3-01 §31 (`fail-61`):** το ΠΔ άρθρο 3 **δεν** περιέχει ρητή διάταξη διακοπής πτήσεων
  (σε αντίθεση με τα άρθρα 1 και 2). Για το Phase II η υποχρέωση διακοπής προκύπτει
  **αποκλειστικά** από την 3-01 §31.
- **Το 100% στις ζωτικές διαδικασίες ανάγκης** (3-01 §25β) **δεν** αναφέρεται πουθενά στο
  Syllabus· το ποιοτικό αντίστοιχο είναι η απαίτηση γνώσης «by heart» της Ενότητας C23XX
  (`gt-59`).
- **Η Εξέταση Καταλληλότητας** είναι θεσμός **αποκλειστικά της 3-01** — δεν κατονομάζεται
  στο ΠΔ άρθρο 3 (`fail-50`).
- **Η ΚΕΠΕ** δεν αναφέρεται **καθόλου** στο ΠΔ 29/2020 (`fail-45`).

| 5 | **Πτήσεις ΕΠΑΝΑΛΗΨΗΣ στο F/S** | §17 (γενική): **3** ανά Στάδιο· §53 (ειδική Phase II): **5** | — | `fail-41`, `fail-42`, `st-45`, `st-46`, `ft-119`, `ft-120` |

**Ειδικά για το #5:** η §32δ(5)(ζ) παραπέμπει σε «παρ. 17 (Phase II)», ενώ η §17 είναι η
**γενική** διάταξη· η ειδική Phase II είναι η §53. Ο αριθμός των διαθέσιμων πτήσεων
ΕΠΑΝΑΛΗΨΗΣ σε ΚΕΠΕ **εξαρτάται από ποια διάταξη ισχύει** — δεν επιλύεται.

### 5.3 ⚠ ΑΣΥΜΜΕΤΡΙΕΣ ΔΙΑΔΡΟΜΗΣ

- **Γραπτές vs προφορικές** (`fail-32`): 2 αποτυχίες σε **γραπτές** → **ΑΠΕΥΘΕΙΑΣ Συμβούλιο**.
  4 αποτυχίες σε **προφορικές** → ενδιάμεση γραπτή εξέταση από ΑΕ. Ο μαθητής που αποτυγχάνει
  σε 2 γραπτές φθάνει στο Συμβούλιο **ταχύτερα**.
- **Ίκαρος vs Ανθυποσμηναγός** (`fail-71`): για τον Ίκαρο η απόφαση επικυρώνεται από το
  **ΓΕΑ με διαταγή**· για τον Ανθυποσμηναγό απαιτείται **οριστική απόφαση ΑΑΣ**.
- **Α/Φ vs F/S στην τελευταία έξοδο ενότητας** (`st-61`): για το **Α/Φ** προβλέπεται Εξέταση
  Καταλληλότητας με Αξιολογητή· για το **F/S** απλή επανάληψη χωρίς Αξιολογητή (3 προσπάθειες).
- **Κλίμακα ΚΕΠΕ vs παραπομπής** (`fail-44`): το κατώφλι ΚΕΠΕ για προφορικές (2/4) είναι
  **ακριβώς το μισό** του κατωφλίου παραπομπής (4/8) — προφανώς σκόπιμο, αλλά **η σχέση δεν
  δηλώνεται ρητά**.
- **Άρθρο 3 vs Άρθρο 4** (`fail-23`): το άρθρο 4 (ΣΜΥΑ, εκτός περιμέτρου) εξαιρεί τις
  περιπτώσεις δ΄ και ε΄(αβ) από τη Δοκιμή Προόδου· το άρθρο 3 τις περιλαμβάνει.
- **Ακρόαση** (`fail-68`): άρθρο 1 (Αξιωματικοί) → **γραπτά**· άρθρο 3 (μαθητές) → **προφορικά**.

### 5.4 ⚠ ΚΙΝΔΥΝΟΣ ΣΥΓΧΥΣΗΣ ΑΡΙΘΜΗΣΗΣ (`fail-85`)

Το ΠΔ άρθρο 3 παρ.1 έχει **11** περιπτώσεις· η 3-01 §58 έχει **12**, επειδή διασπά την
περίπτωση των προφορικών σε δύο εδάφια (§58ζ = κριτήριο, §58η = επανεξέταση). **Από το
γράμμα «ζ» και μετά η 3-01 είναι μετατοπισμένη κατά ένα γράμμα:**

```
ΠΔ 1α…1στ  =  3-01 §58α…§58στ        (ταυτίζονται)
ΠΔ 1ζ      =  3-01 §58ζ + §58η        (μία περίπτωση ΠΔ → δύο εδάφια 3-01)
ΠΔ 1η      =  3-01 §58θ    (απειθαρχία)
ΠΔ 1θ      =  3-01 §58ι    (έγγραφη απαρέσκεια)
ΠΔ 1ι      =  3-01 §58ια   (ουσίες)
ΠΔ 1ια     =  3-01 §58ιβ   (αεροπορικό ατύχημα)
```

> Το ΠΔ παρ.5 παραπέμπει στις «υποπαραγράφους **1στ, 1η, 1θ και 1ι**». Αν κάποιος διαβάσει
> τα **ίδια γράμματα** στην αρίθμηση της 3-01 §58, θα προκύψουν **ΛΑΘΟΣ** περιπτώσεις.
> Κάθε αυτοματοποιημένος έλεγχος πρέπει να δηλώνει ρητά την πηγή αρίθμησης.

### 5.8 Ασάφειες μέτρησης που επηρεάζουν κάθε αυτοματοποίηση

1. **«Συνεχόμενες» πτήσεις** (`fail-76`, `fail-88`): η 3-01 §43 ορίζει ότι ΕΠΑΝΑΛΗΨΕΙΣ, ΑΔΕ,
   επαναδιαθέσεις και πτήσεις εθισμού **δεν βαθμολογούνται**, άρα δεν παράγουν 0-59%.
   **Παραμένει ανοικτό** αν μια τέτοια έξοδος **διακόπτει** (μηδενίζει) τη μέτρηση ή απλώς
   **παρακάμπτεται**. Επίσης δεν καλύπτονται οι πτήσεις **ΜΟΝΟΣ**, που βαθμολογούνται.
2. **Παρονομαστής του 20%/40%** (`fail-77`): προγραμματισμένες ή εκτελεσθείσες; Περιλαμβάνει
   F/S, ΜΟΝΟΣ, ΕΠΑΝΑΛΗΨΕΙΣ, ΑΔΕ; **Δεν διευκρινίζεται.**
3. **Αριθμός πτήσεων «ΠΡΟ ΜΟΝΟΣ»** (`fail-77`): **δεν προσδιορίζεται σε καμία πηγή**, οπότε
   το 40% **δεν είναι άμεσα υπολογίσιμο**.
4. **«4 πρώτες έξοδοι του σταδίου»** (`fail-76`): μόνο Α/Φ ή και F/S; Το κριτήριο F/S
   χρησιμοποιεί «3 πρώτες εξόδους», γεγονός που υποδηλώνει χωριστή μέτρηση **χωρίς να δηλώνεται**.
5. **Αφετηρία της 10ήμερης προθεσμίας** (`fail-67`): «από την ημερομηνία της **τελευταίας
   πτήσης**». Για λόγους παραπομπής **μη σχετιζόμενους με πτήση** (1στ, 1η, 1θ, 1ι) η
   αφετηρία είναι **δυσχερώς προσδιορίσιμη**.
6. **Βαθμολογία επαναξιολόγησης** (`fail-34`, `gt-51`, `st-71`): «δεν λαμβάνεται υπόψη» —
   **δεν διευκρινίζεται** αν διατηρείται η αρχική (αποτυχούσα) ή αν το αντικείμενο εξαιρείται
   πλήρως από τον Μ.Ο.
7. **«Ακρίβεια χιλιοστών»** (`fail-60`): η αντιστοίχιση σε **3 δεκαδικά ψηφία** είναι
   **ερμηνεία υλοποίησης**, όχι τιμή της πηγής, και έχει αφαιρεθεί από τα `values`.
8. **§30δ(1) vs §30ε** (`fail-10`): η πρώτη ορίζει **μεθεπόμενη** εργάσιμη, η δεύτερη
   **επόμενη**. Η σχέση ειδικού/γενικού κανόνα **δεν διευκρινίζεται**.
9. **§35 vs §37** (`fail-54`): η §35 βαθμολογεί την ΑΕΡΟΝΑΥΤΙΑ με ΥΣΤΕΡΗΣΗ (59%)· η §37
   ορίζει ότι η πτήση βαθμολογείται **μόνο** αν πρέπει να χαρακτηριστεί ΑΠΟΤΥΧΙΑ υπό τις
   προϋποθέσεις 75%/75%. **Δεν συμβιβάζονται ρητά.**
10. **«ΠΔ 29/2020 κατά περίπτωση»** (`fail-09`, `fail-11`): οι διατάξεις **δεν
    προσδιορίζουν** ποια υποπαράγραφο ενεργοποιούν· η αντιστοίχιση είναι **ερμηνευτική**.
11. **Κώδικες → ποσοστά** (`fail-89`): η μετάβαση από τους Κώδικες Απόδοσης («4», «3», «2»,
    «1», «0», «D») στην εκατοστιαία Γενική Απόδοση **δεν περιγράφεται αλγοριθμικά σε καμία
    πηγή**.
12. **Παρ.9 vs παρ.7** (`fail-26`): η παρ.9 συνδέει το δικαίωμα του Δκτή Μοίρας με την επίδοση
    στην «προηγούμενη Δοκιμή Προόδου από τον ΑΕ», αλλά η παρ.7 επιτρέπει στον ΑΕ **μόνο μία**
    κρίση ανά στάδιο. **Δεν διευκρινίζεται** πώς εφαρμόζεται η παρ.9 όταν η 2η παραπομπή
    πηγαίνει απευθείας στον Δκτή Μοίρας.

## 6. Η απάντηση σε σύνοψη: «πόσες φορές χωρίς Συμβούλιο»

Πλήρης ανάλυση στο `board_tolerance_matrix.json`. Συνοπτικά:

| Είδος αποτυχίας | Ανεκτές φορές | Ενδιάμεσα σκαλιά |
|---|---|---|
| Απειθαρχία / απαρέσκεια / ουσίες (1η, 1θ, 1ι) | **0** | **κανένα** — απευθείας Συμβούλιο |
| Αεροπορικό ατύχημα με ευθύνες ΕΔΕ (1ια) | **0** | απευθείας **ΑΑΣ** (όχι Συμβούλιο) |
| 2 συνεχόμενες γραπτές εδάφους (1στ) | **1** γραπτή | ΚΕΠΕ → **απευθείας Συμβούλιο** |
| 0-59% σε checkride (1β) | **0** | Δοκιμή Προόδου ΑΕ → Δκτής Μοίρας → Συμβούλιο |
| Επικίνδυνος χειρισμός (1α) | **0** | Δοκιμή Προόδου ΑΕ → Δκτής Μοίρας → Συμβούλιο |
| Διαδοχικές χαμηλές αέρος (1γ) | **1** × 0-49% ή **2** × 0-59% | Δοκιμή Προόδου ΑΕ → Δκτής Μοίρας → Συμβούλιο |
| Σωρευτικό ποσοστό (1δ) | < 40% ΠΡΟ ΜΟΝΟΣ / < 20% συνόλου | Δοκιμή Προόδου ΑΕ → Δκτής Μοίρας → Συμβούλιο |
| Αποτυχίες F/S (1ε) | **2** διαδοχικές | Δοκιμή Προόδου **στον εξομοιωτή** → Δκτής Μοίρας → Συμβούλιο |
| 4/8 προφορικές (1ζ) | **3** συνεχ. / **7** μη συνεχ. | ΚΕΠΕ (στις 2/4) → γραπτή ΑΕ → Συμβούλιο ⚠ *βλ. §5.1 #1* |
| Τελευταία πτήση ενότητας Α/Φ | **1** (+ Εξέταση Καταλληλότητας) | Εξέταση Καταλληλότητας → ΠΔ |
| Τελευταία έξοδος ενότητας F/S | **2** | επανάληψη → +2 ημέρες → επανάληψη → ΠΔ |
| Μεμονωμένη ΥΣΤΕΡΗΣΗ/ΑΠΟΤΥΧΙΑ (Α/Φ ή F/S) | **άνευ αυτοτελούς ορίου** | αναπρογραμματισμός + ΚΕΠΕ· μετράει σωρευτικά στα 1γ/1δ/1ε |
| ≤59% → απαγόρευση επόμενης «ΜΟΝΟΣ» | **άνευ ορίου ως προς Συμβούλιο** | Dual στην ίδια κατηγορία + ΚΕΠΕ |

**Το καθοριστικό όριο (`fail-26`):** ο ΑΕ κρίνει **1 φορά** ανά στάδιο· ο Δκτής Μοίρας
**1 φορά** (αν η Δοκιμή ΑΕ ήταν ≥60%) ή **2 φορές** (αν ήταν <60%). Σύνολο **2 ή 3 Δοκιμές
Προόδου**. Μετά την εξάντληση, **κάθε** νέα κρίση οδηγεί στο Συμβούλιο **χωρίς πτήσεις
Δοκιμής Προόδου**.
